# Computational-Quality-Assessment-Refinement-and-Validation-of-the-PCNA-E113G-Mutant-Structure
Computational quality assessment, refinement, and validation of the PCNA E113G mutant structure (PDB: 3GPM). The project evaluates structural quality using ERRAT, VERIFY3D, and PROCHECK, followed by refinement and pre-/post-validation comparison to assess improvements in protein model quality.
